プライバシーポリシー

最終更新日: 2026年9月8日

1. 適用範囲

本ポリシーは、Spoje-128（以下「開発者」）が個人的な用途のために開発・運用しているパーソナルアシスタントツール Hermes（以下「本ツール」）に適用されます。本ツールは一般公開されているサービスではなく、開発者本人が自身のアカウントに対してのみ使用します。

2. 取得する情報

本ツールは、利用者本人の同意に基づき Google API を通じて以下の情報にアクセスします。

  • Google カレンダーの予定（calendar スコープ）
  • Gmail のメッセージの読み取りおよびラベル・既読状態の変更（gmail.readonly / gmail.modify スコープ）

アクセスするのは、認証を行った本人のアカウントのデータに限られます。第三者のアカウントからデータを取得することはありません。

3. 利用目的

取得した情報は、予定およびメールの要約・整理・通知という、利用者本人に対する提示のみに使用します。それ以外の目的には使用しません。

4. 保存場所と保存期間

取得したデータおよび OAuth トークンは、開発者が管理する自宅内の私有サーバー（Raspberry Pi）のローカルストレージにのみ保存されます。外部のクラウドストレージやデータベースには保存しません。不要になった時点で削除します。

5. 第三者への提供

取得した情報を第三者に販売・貸与・提供することはありません。広告目的での利用、および利用者本人以外への開示は行いません。

要約の生成のために外部の大規模言語モデル API に本文の一部を送信する場合がありますが、これは利用者本人の要求を処理する目的に限られ、送信先での学習利用を許諾していない事業者を選択しています。

6. Google ユーザーデータの取り扱い

本ツールによる Google API から取得した情報の使用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。

7. アクセス権の取り消し

利用者はいつでも Google アカウントの権限設定から本ツールのアクセス権を取り消すことができます。取り消し後、本ツールは新たなデータを取得しません。

8. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub プロフィールに記載の連絡先までご連絡ください。

9. 改定

本ポリシーは必要に応じて改定されます。改定した場合は本ページの最終更新日を更新します。
